====================================================
  CARA LOGIN DI POSTMAN
====================================================

1. Method  : POST
   URL     : http://localhost:8000/api/login
   Body    : raw → JSON
   {
     "email": "admin@gmail.com",
     "password": "admin123"
   }

2. Salin nilai "token" dari response.

3. Di setiap request selanjutnya, tambahkan Header:
   Authorization : Bearer <token_disini>
   Accept        : application/json
